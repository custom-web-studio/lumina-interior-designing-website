# Lumina Interior Designing Website

A fully responsive, modern landing page built for a luxury interior design studio.

## 🔗 Live Demo
Check out the live website here: [https://custom-web-studio.github.io/lumina-interior-designing-website/](https://custom-web-studio.github.io/lumina-interior-designing-website/)

## ✨ Features
* **Responsive Design:** Custom CSS media queries tailored for desktops, tablets, and mobile devices (850px and 480px breakpoints).
* **Interactive UI:** Clean navigation, portfolio showcases, client reviews, and custom-styled buttons with smooth layout transitions.
* **Client Contact System:** Integrated form submission system powered by Web3Forms for seamless client outreach.
* **Typography & Styling:** Styled with CSS Flexbox, CSS Grid, and custom Google Fonts.

## 🛠️ Built With
* **HTML5**
* **CSS3** (Flexbox & Grid)
* **JavaScript**
